# Map attribution

The holdings map uses the **RuneScape: Dragonwilds** world-map art:

- In-game texture: `T_WorldMap_Landmass` (6144×6144)
- Calibration: `size=485000`, `ox=-42500`, `oy=-147500` (Unreal cm)
- Bundled image: stitched from community-hosted tiles that reproduce that landmass
- **Map © Jagex**

This is for a private local server dashboard. Do not redistribute the map asset commercially.
